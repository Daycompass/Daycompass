# Screenward

Screenward is an open-source, self-hosted screentime backend for students,
built so schools and individuals can run their own instance instead of
relying on a third-party service.

## Status: early development

This repository currently contains only the project foundation: workspace
layout, CI, and security tooling. There is no database, no
authentication, and no API yet. Expect breaking changes at any time.
